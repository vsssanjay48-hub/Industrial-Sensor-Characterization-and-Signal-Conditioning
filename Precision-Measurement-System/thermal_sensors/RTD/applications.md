# RTD Applications

## 1. Industrial Process Control
Chemical reactors, distillation columns, heat exchangers. Class B PT100 in SS sheath, 3-wire, head-mounted 4–20 mA transmitter. Interchangeable without recalibration (within Class B tolerance).

## 2. HVAC
Supply/return air, chilled water, hot water pipes. Long cable runs make lead resistance critical → 3-wire. ΔT accuracy (2–10°C) demands ±0.5°C → RTD preferred over thermocouple.

## 3. Laboratory and Calibration Standards
SPRTs (Standard Platinum Resistance Thermometers) define ITS-90. Class AA RTDs calibrated against SPRTs in stirred baths. Used to calibrate field sensors. Achievable accuracy: ±0.01°C.

## 4. Pharmaceutical and Food (GMP/HACCP)
Autoclaves, freeze-dryers, cold storage, pasteurization. Traceable calibration certificates required. RTD stability and interchangeability essential for regulatory compliance.

## 5. Aerospace
Turbine casing temperatures, cabin control, avionics. Thin-film RTDs for vibration tolerance. Shielded cables for EMI.

## Selection: RTD vs Thermocouple vs Thermistor
| Criterion | Choose RTD when... |
|---|---|
| Accuracy | Need better than ±1°C |
| Stability | Long-term use, minimal recalibration |
| Range | −200 to +600°C |
| Compliance | Traceable calibration required |
| Response time | > 1 second acceptable |
