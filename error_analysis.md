# Error Analysis

## Introduction

Every real measurement contains error. This is not a deficiency to be apologized for — it is a fundamental property of physical measurement that must be understood, quantified, and managed. The engineer's job is not to eliminate error (impossible) but to:

1. Identify all sources of error in the system
2. Quantify the magnitude of each source
3. Understand how errors combine through the measurement chain
4. Implement techniques to reduce errors to within acceptable limits
5. Report measurements with honest uncertainty statements

This document develops a rigorous framework for error analysis as applied to the precision thermal measurement system.

---

## Classification of Errors

### Systematic Errors (Bias)

Systematic errors are consistent, repeatable errors that shift all measurements in the same direction by approximately the same amount. They cannot be averaged away with repeated measurements.

Sources of systematic error in thermal measurement systems:

**Calibration error:** The sensor's transfer function has a consistent offset or gain error from the nominal value. Example: A PT100 RTD that reads 101.5 Ω at 0°C instead of the nominal 100.0 Ω has an offset calibration error of +1.5 Ω (≈+3.9°C).

**Lead wire resistance:** In a 2-wire RTD connection, the resistance of the connecting wires adds directly to the measured resistance. For 10 m of 0.5 mm² copper wire:
```
R_lead = ρ · L / A = (1.72×10⁻⁸ Ω·m × 10 m) / (0.196×10⁻⁶ m²) ≈ 0.88 Ω
```
This represents a temperature error of approximately 0.88/0.385 ≈ 2.3°C — significant for precision work.

**Self-heating:** The excitation current through a resistive sensor dissipates power that heats the sensor element, causing it to read higher than the true ambient temperature. (Quantified in detail in `thermal_sensors/RTD/limitations.md`.)

**Thermal EMF (thermoelectric offset):** Dissimilar metals in connections generate parasitic thermoelectric voltages (Seebeck effect). These appear as DC offsets in voltage measurements and are particularly problematic in low-level thermocouple measurements.

**Amplifier offset voltage:** Op-amps have a small input offset voltage (typically 0.1–5 mV) that appears as a gain-multiplied offset error at the output. For an INA with gain 100 and offset 1 mV, the output offset is 100 mV — equivalent to a significant temperature error.

**Reference junction error (thermocouple):** If the cold junction compensation is incorrect, all thermocouple readings will have a systematic offset equal to the CJC error.

### Random Errors (Noise)

Random errors are unpredictable, zero-mean fluctuations that cause readings to scatter around the true value. They can be characterized statistically and reduced by averaging.

Sources of random error:

**Johnson-Nyquist (Thermal) Noise:** Generated by thermal motion of electrons in any resistor. Unavoidable, sets the fundamental noise floor.
```
V_n,rms = √(4 k_B T R BW)
```
Example: R = 100 Ω, T = 300 K, BW = 1 Hz:
```
V_n = √(4 × 1.38×10⁻²³ × 300 × 100 × 1) = 1.29 nV/√Hz
```

**1/f (Flicker) Noise:** Low-frequency noise whose power spectral density increases as frequency decreases. Dominates at very low frequencies (below ~1–100 Hz depending on the device). Expressed as:
```
S_v(f) = K_f / f
```
Where K_f is a device-specific constant.

**Shot Noise:** Associated with DC current flow through a barrier (e.g., diode junction). Not dominant in most resistive sensor circuits but important in semiconductor sensor interfaces.

**Electromagnetic Interference (EMI):** External electric and magnetic fields couple into measurement circuits. Sources include power lines (50/60 Hz), switching regulators, motors, and radio frequency transmitters.

**Power Supply Noise:** Ripple and switching transients on supply rails couple into signal paths through imperfect power supply rejection.

**Quantization Noise:** When an ADC digitizes the signal, each sample is rounded to the nearest LSB. The quantization error is uniformly distributed between -½LSB and +½LSB. RMS quantization noise:
```
V_q,rms = (FSO / 2^N) / √12 = LSB / √12
```

## Absolute and Relative Error

**Absolute error** has the same units as the measured quantity:

```
ΔX = X_measured - X_true
```

**Relative error** is dimensionless (or expressed as a percentage):

```
ε_r = ΔX / X_true = (X_measured - X_true) / X_true
```

**Percentage error:**
```
ε_% = (ΔX / X_true) × 100%
```

**Combined absolute error bound:** When the absolute error of a measurement comes from multiple independent sources (ε₁, ε₂, ε₃, ...):

*Worst case (conservative):*
```
ε_total = |ε₁| + |ε₂| + |ε₃| + ...
```

*Statistical (RSS — Root Sum of Squares):*
```
ε_total = √(ε₁² + ε₂² + ε₃² + ...)
```

The RSS method is more realistic when errors are independent and randomly distributed. The worst-case method is appropriate for safety-critical applications.

## Error Propagation

When a measured quantity Z is calculated from several independently measured variables X, Y, W:

```
Z = f(X, Y, W)
```

The propagated uncertainty in Z is:

```
ΔZ = √[(∂f/∂X · ΔX)² + (∂f/∂Y · ΔY)² + (∂f/∂W · ΔW)²]
```

The partial derivatives ∂f/∂X, ∂f/∂Y, ∂f/∂W are the **sensitivity coefficients** — they tell you how much uncertainty in each input variable contributes to uncertainty in the output.

### Example: Wheatstone Bridge Temperature Measurement

For a bridge with one active RTD arm (R1), three fixed arms (R2 = R3 = R4 = R₀), excitation voltage V_ex:

Bridge output voltage:
```
V_out = V_ex × [R1/(R1+R2) - R4/(R3+R4)]
```

At balance (R1 = R₀):
```
V_out = 0
```

For small resistance change δR from balance:
```
V_out ≈ V_ex × δR / (4 R₀)     [Quarter-bridge, small δR approximation]
```

Temperature from resistance change (RTD linear model):
```
T = δR / (R₀ · α)
```

So the bridge output in terms of temperature is:
```
V_out ≈ V_ex × R₀ · α · ΔT / (4 R₀) = V_ex · α · ΔT / 4
```

Error propagation: If V_ex has uncertainty ΔV_ex and α has uncertainty Δα:

```
ΔT = √[(∂T/∂V_out · ΔV_out)² + (∂T/∂V_ex · ΔV_ex)²]
```

Where:
```
∂T/∂V_out = 4 / (V_ex · α)
∂T/∂V_ex = -4 V_out / (V_ex² · α)    = -ΔT / V_ex
```

This shows that excitation voltage instability directly translates to temperature error — hence the use of stable, regulated voltage references (not raw supply rails) for precision bridges.

### Example: RTD Self-Heating Error

The self-heating error (derived fully in RTD limitations doc):
```
ΔT_sh = I² × R(T) × R_th
```

Where R_th is the sensor thermal resistance to ambient.

If we measure I with uncertainty ΔI and R with uncertainty ΔR:
```
ΔT_sh_error = √[(2 I R R_th · ΔI)² + (I² R_th · ΔR)²]
```

Since the self-heating error is proportional to I², even small uncertainties in the excitation current produce magnified temperature errors. This is why low-noise, stable current sources are critical.

## Statistical Treatment of Random Errors

For N repeated measurements x₁, x₂, ..., x_N of a stable quantity:

**Sample mean (best estimate of true value):**
```
x̄ = (1/N) Σ xᵢ
```

**Sample standard deviation (measure of spread):**
```
s = √[(1/(N-1)) Σ (xᵢ - x̄)²]
```

**Standard error of the mean:**
```
SE = s / √N
```

The standard error decreases as √N — averaging reduces random error but not systematic error. To halve the random error, you need 4× as many measurements.

**Confidence intervals (Gaussian assumption):**

| Confidence Level | Interval |
|---|---|
| 68.3% | x̄ ± 1σ |
| 95.4% | x̄ ± 2σ |
| 99.7% | x̄ ± 3σ |

For small N (< 30), use the Student's t-distribution:
```
x̄ ± t_(α/2, N-1) × (s / √N)
```

## Noise Characterization

### Noise Spectral Density

Noise is characterized by its power spectral density (PSD) S(f), with units V²/Hz. The RMS noise over a bandwidth from f₁ to f₂ is:

```
V_n,rms = √[∫(f₁ to f₂) S(f) df]
```

For white noise (frequency-independent): S(f) = S₀
```
V_n,rms = √(S₀ × BW)
```

For 1/f noise: S(f) = K_f / f
```
V_n,rms = √(K_f × ln(f₂/f₁))
```

The total noise in a system with both white and 1/f noise:
```
V_n,rms = √[K_f × ln(f₂/f₁) + S₀ × (f₂ - f₁)]
```

The frequency where 1/f noise power equals white noise power is the **corner frequency** f_c:
```
f_c = K_f / S₀
```

For frequencies well above f_c, white noise dominates. Below f_c, 1/f noise dominates. For DC measurements and very low frequency sensing, 1/f noise is often the dominant noise mechanism.

### Noise Figure

Noise Figure (NF) describes how much noise an amplifier adds to the signal:
```
NF = 10 · log₁₀(SNR_in / SNR_out)    [dB]
```

An ideal noiseless amplifier has NF = 0 dB. Real amplifiers add noise, so NF > 0 dB.

For a cascade of stages (Friis formula):
```
F_total = F₁ + (F₂ - 1)/G₁ + (F₃ - 1)/(G₁G₂) + ...
```

Where F = noise factor (linear), G = power gain.

The first stage amplifier dominates overall noise figure — this is why a low-noise preamplifier close to the sensor is critical in precision instrumentation.

## Noise Sources in the RTD Measurement Chain

| Stage | Noise Source | Typical Magnitude |
|---|---|---|
| RTD element | Johnson noise | 1.3 nV/√Hz at 100Ω, 300K |
| Lead wires | Johnson noise (add lead R) | Proportional to lead resistance |
| Excitation source | Current noise | Depends on source quality |
| INA input | Voltage noise | ~1–10 nV/√Hz (low-noise INA) |
| INA input | Current noise | ~1–10 pA/√Hz (creates voltage noise with source impedance) |
| Filter resistors | Johnson noise | Adds to noise floor |
| ADC | Quantization noise | LSB/√12 |

**Total referred-to-input (RTI) noise:**
```
V_n,RTI = √(V_n,RTD² + V_n,INA² + ...)
```

**Referred to temperature (RTT):**
```
T_n,RTT = V_n,RTI / (S_sensor × G_bridge)
```

Where S_sensor is the sensor sensitivity and G_bridge is the bridge sensitivity.

## Error Budget

An error budget is a structured accounting of all error sources in a measurement system. It helps identify which errors dominate and where effort should be focused.

**Example error budget for a PT100 RTD system:**

| Error Source | Type | Magnitude (°C) | Method |
|---|---|---|---|
| RTD calibration error | Systematic | ±0.3 | 2-point calibration |
| Lead wire resistance (2-wire) | Systematic | ±2.3 | 4-wire eliminates this |
| Self-heating (1 mA excitation) | Systematic | ±0.1 | Reduce current, correct |
| Amplifier offset drift | Systematic | ±0.05 | Low-drift INA, autozero |
| Reference voltage error | Systematic | ±0.1 | Stable reference |
| Thermal noise (1 Hz BW) | Random | ±0.001 | Filter to needed BW |
| EMI | Random | ±0.05 | Shielding, twisted pair |
| ADC quantization (16-bit) | Random | ±0.0008 | Sufficient resolution |
| **Total (RSS)** | | **≈ ±2.35** | 2-wire uncorrected |
| **Total (4-wire, calibrated)** | | **≈ ±0.33** | After corrections |

This illustrates that lead resistance dominates in an uncorrected 2-wire setup, and that careful system design can reduce total error by nearly an order of magnitude.

## Minimization Techniques

### Shielding
- Electrostatic shields (copper/aluminum foil) around signal cables reduce capacitively-coupled EMI
- Connect shield to one end only (single-point ground) to prevent ground loop currents

### Differential Signaling
- Transmit the sensor signal as a differential pair (V+ and V−)
- Common-mode noise couples equally to both conductors and is rejected by the differential amplifier's CMRR
- Effective for long cable runs in electrically noisy environments

### Filtering
- Apply a low-pass filter to limit bandwidth to what is needed
- Reduces the integrated noise power: lower BW → less noise
- Trade-off: lower BW → slower response time

### Calibration
- Systematic errors can be corrected by calibration
- Two-point calibration corrects offset and gain error
- Multi-point polynomial calibration corrects non-linearity
- Calibration does not help random errors

### Averaging
- Averaging N samples reduces random noise by √N
- Equivalent to reducing bandwidth: f_eff = f_sample / (2N)
- Very effective for slow-varying measurements

### Twisted Pair Cables
- Magnetically induced EMI is proportional to the loop area of the cable
- Twisting the signal wires reduces the effective loop area, dramatically reducing magnetic coupling

### Guard Rings (for very high impedance sensors)
- PCB guard traces at the same potential as the high-impedance signal node prevent leakage currents

### Proper Grounding
- Star (single-point) grounding prevents ground currents from adding noise
- Separate analog and digital ground planes, connected at one point

## Conclusion

Error analysis is not a post-measurement exercise — it must be built into the system design from the beginning. The key questions to ask at every design stage are:

1. What errors does this component or configuration introduce?
2. What is the magnitude of each error?
3. Is this error systematic (can be calibrated) or random (must be filtered/averaged)?
4. What is the contribution of this error to the total measurement uncertainty?
5. Is the total uncertainty acceptable for the application?

The error budget approach, combined with error propagation mathematics, transforms these questions into quantitative answers.
